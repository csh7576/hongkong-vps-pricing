## 一台香港 VPS 的价格由哪几件事决定

**回内地走什么线路。** 这一项占大头。CN2 GIA、CMI、CUG 这类运营商精品线路的带宽成本，是普通国际 BGP 的好几倍。同样的 CPU 和内存，线路从国际 BGP 换成 CN2 GIA，价格翻两三倍很常见。

**带宽是 50Mbps 还是 4Gbps。** 很多便宜的香港 VPS 打着"不限流量"，实际端口只有 10Mbps 到 50Mbps，跑满也就那样。反过来，给到 Gbps 级端口的套餐，通常改成按月给流量额度。

**流量怎么算。** 单向还是双向、超量之后是断流还是降速、降到多少，这三条比"给你多少 TB"更能决定月底的体验。超量降速到 100Mbps 继续跑，和直接停机，是两种完全不同的产品。

**硬件。** AMD EPYC 新平台、NVMe、宣称不超售，这些确实要成本，但在香港这个价格体系里，它们排在网络后面。

## 几个常见问题

**香港 VPS 为什么比美国贵这么多？**
因为香港到内地的物理距离近，而近就等于贵。机房租金、带宽落地成本、CN2 GIA 这类线路的采购价，全都在往上叠。美国洛杉矶同规格配置配 CN2 GIA，价格通常只有香港的几分之一。

**$6.9/月的香港 VPS 能不能用来建站？**
能用，但前提是你的访客不在内地，或者你能接受内地访问绕路。这一个价格档买的是"香港 IP + 大带宽 + 国际线路"，不是"国内访问快"。

**年付一定更划算吗？**
单价上通常是。但年付意味着把预算锁定一年，而你面对的是一个会调整价格、会更新平台、会补货换代的商家。第一次用某个商家，先按季付试一个周期，比一上来就年付稳一点。

**香港 VPS 需要备案吗？**
不需要，这是很多人选香港节点的直接原因。
